# CLAUDE.md — tidywigits

nemo child R package that parses and tidies WiGiTS suite outputs (Hartwig Medical Foundation).
For deep context use the routing table in `tidywf/CLAUDE.md` — auto-loaded by Claude Code from the parent directory.

## Structure

- `R/<ToolName>.R` — one Tool subclass per WiGiTS tool, inheriting `nemo::Tool`
- `R/Wigits.R` — workflow class inheriting `nemo::Workflow`; several tools registered
- `inst/config/tools/<tool>/schema.yaml` — nemo custom schema per tool → `tidywf/docs/r-pkg/schema.md`
- `R/utils.R` — defines `pkg_name <- "tidywigits"`, passed to every `super$initialize()`

## Critical gotchas

- Never write test files manually — regenerated by `devtools::document()` via roxytest `@testexamples` blocks
- Purple has an extra `inst/config/tools/purple/plots.yaml` (8 plot types) alongside its `schema.yaml`, used for
  downstream reporting and visualisation

## AWS helper

`s3sync(src, dest, pats)` in `R/s3.R` wraps `aws s3 sync` with include/exclude patterns
covering all tools.
